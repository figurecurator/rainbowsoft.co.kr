01 / 피규어 카탈로그

피규어 큐레이터

찾던 피규어와 판매처를 한곳에서.

상품명이나 캐릭터로 둘러보고, 제품 번호나 JAN으로 원하는 판본을 찾아보세요. 상품 상세에서 등록된 판매처와 가격 정보를 확인할 수 있습니다.

서비스 열기 ↗
shell

$ samlgate login

브라우저에서 SAML 로그인

$ aws sts get-caller-identity --profile saml

02 / 오픈소스 CLI

samlgate

브라우저 로그인으로 AWS CLI 시작하기.

평소 쓰는 브라우저에서 조직 계정으로 로그인하면, samlgate가 AWS STS 임시 자격 증명을 받아 CLI 프로필에 저장합니다. Windows와 Apple Silicon Mac용 배포본을 제공합니다.

코딩 에이전트로 설정하기

Claude Code나 Codex에 아래 문장을 붙여 넣으면 설치, 첫 로그인, 에이전트 지침 추가까지 진행합니다.

Set up samlgate for AWS sign-in on this computer by following
https://raw.githubusercontent.com/figurecurator/samlgate/main/docs/agent-setup.md
